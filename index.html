01About

I’m a cybersecurity-focused Computer Science student at the University of Louisville’s J.B. Speed School of Engineering, graduating in December 2027. What pulls me in is AI and autonomous agents — like a research agent that trains models, reads its own results, and rewrites its next experiment with no human in the loop.

02Selected work

Things I’ve shipped.

Detection engineering

siglint

A detection-as-code CLI that scans logs against Sigma rules and pushes findings into GitHub’s Security tab via SARIF — the detection-as-code idea, shrunk to a single command you can run in CI.

Python · Sigma · SARIF · GitHub Actions

  • 3,136 of 3,161 SigmaHQ rules load and validate.
  • Implements Sigma’s full condition grammar, down to 1 of selection_*, plus modifiers like windash, cidr, and re.
  • Per-source-IP thresholds catch brute force; --fail-on high gates a CI pipeline.

AI agents

autolab

An LLM agent that runs the whole ML research loop: hypothesis, experiment on any model or task, read the results, plan the next run.

  • Every run is versioned and replayable to the exact metric.
  • The demo drives a real search with no API key, GPU, or training.
  • Grew out of Auto-Research for SLMs, which ran 20 self-directed experiments per overnight cycle.

Python · PyTorch · Anthropic API

Quant

axiom-backtest

An event-driven backtester built to answer one question honestly: would this survive out-of-sample, after costs?

  • Four slippage models, from fixed to order-book depth-aware.
  • 126× faster data alignment — 10M rows in about 8.5 seconds.
  • Walk-forward validation built in; the case study reports that its strategy underperforms buy-and-hold SPY.

Python · pandas · Statistics
